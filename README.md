# Portfolio-HTML


**Live Demo:** [Portfolio-HTML](https://amruthapaalathara.github.io/Portfolio-HTML/)  

## About the Project  

This is my personal portfolio website, designed and developed using **HTML** and **Bootstrap CSS**. The website serves as a digital resume where I showcase my background, education, skills, and the projects I have worked on. It provides a structured and visually appealing way to present my work and professional journey.  

## Features  

- **About Me** – A section that gives a brief introduction about myself.  
- **Educational Qualifications** – Displays my academic background and achievements.  
- **Projects** – A showcase of the various projects I have worked on, along with descriptions and relevant links.  
- **Skills** – Highlights my technical and soft skills.  
- **Responsive Design** – Built with Bootstrap CSS to ensure compatibility across different screen sizes.  

## Technologies Used  

- **HTML** – To structure the content of the website.  
- **Bootstrap CSS** – For styling and responsiveness.

## Other explored technologies

- **Tailwind CSS** – Explored briefly while building the website.  
- **JavaScript (Basic)** – Used for minor interactive elements.  

## What I Learned  

While developing this website, I gained valuable experience in:  

- Structuring web pages using **HTML** efficiently.  
- Implementing **Bootstrap CSS** for creating responsive and visually appealing designs.  
- Understanding the basics of **Tailwind CSS** and how it differs from Bootstrap.  
- Learning **basic JavaScript** to add simple interactive features.
